Research

LLM agents and multi-agent systems

How a team of LLM agents is wired together can matter as much as the model behind each agent. I study how to learn that structure with reinforcement learning, and how to give enterprise agents realistic environments to learn in before they meet production systems.

  • Learning how teams of LLM agents should collaborate

    First author, under review at ICLR 2027

    A reinforcement learning method that decides, for each task, how agents divide work and communicate, and uses execution feedback to recover from failures. Evaluated on competitive programming and math reasoning.

  • Executable replicas of enterprise software for agent training

    Team lead and co-author, NeurIPS 2026

    Turns the manuals and API documentation of closed-source applications into runnable environments with databases, APIs and agent tools. Training inside the replicas with structured task guidance raised an 8B model’s task accuracy by 52%.

Efficient and scalable graph learning

No single graph neural network wins on every graph, and the strongest ones rarely fit in GPU memory on real data. I build methods that choose models adaptively and train within a fixed memory budget at web scale.

  • Self-Adaptive Graph Mixture of Models

    First author, AAAI 2026

    Learns, for every node, which graph neural network architectures to use and how to combine them, pruning weak ones during training. Matched or outperformed strong baselines on 16 benchmarks, with gains of up to 22% on link prediction.

  • Memory-efficient training on web-scale graphs

    First author, under review at AAAI 2027

    A theoretically grounded framework for training graph neural networks on graphs with hundreds of millions of nodes and billions of edges within a fixed GPU memory budget.

  • Matrix sketching for fast graph neural network training

    Co-author, TMLR 2026

    Compresses the graph before training with Proper Orthogonal Decomposition. Trains on a 111M-node graph in under 8 GB of GPU memory with about 339× faster epochs.

Graph AI with clients

I translate client problems into graph learning systems and see them through from requirements to deployment.

  • Real-time fraud detection for an enterprise client in Vietnam

    Proof of concept

    Worked on site in Hanoi to define fraud scenarios, data and success criteria, and wrote the proposal for a streaming graph AI system built on Kafka, Flink and JanusGraph.

  • Tax-evasion detection on a billion-node graph

    Client deployment

    An end-to-end pipeline on a heterogeneous graph with billions of nodes, with a graph transformer robust to scarce labels and hub nodes, and an interactive viewer for million-node graphs.

Patents. Three applications filed through Fujitsu, on adaptive fusion of graph learning models, memory-efficient training on large graphs, and collaboration structures for multi-agent LLM systems.
